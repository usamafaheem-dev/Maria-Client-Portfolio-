# Maria Client Portfolio

A modern, single-page portfolio website for **Maria Yasin (Software Engineer)**, built with clean HTML, CSS, and JavaScript.

## Overview

This project showcases Maria’s profile, services, skills, project work, education, and contact details in an interactive and responsive layout.

## Features

- Responsive single-page design
- Animated sections, counters, and progress bar
- Sticky navigation with active section highlighting
- Mobile drawer menu
- Smooth scrolling with fixed-header offset support
- Reduced-motion support for accessibility
- Downloadable CV integration
- Direct contact actions (email, phone, WhatsApp)

## Tech Stack

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
- Google Fonts
- Devicon CDN icons

## Getting Started

Because this is a static frontend project, no build step is required.

1. Clone the repository.
2. Open `index.html` in your browser.

For local development with auto-reload, you can use any static server (for example VS Code Live Server).

## Customization Guide

### Personal Content
Edit content in:
- `index.html`

Update:
- Name, bio, and section text
- Project descriptions
- Skills and percentages
- Education/experience timeline
- Contact info (email/phone/WhatsApp)

### Styling
Edit visual theme in:
- `assets/css/style.css`

Main colors and typography are controlled via CSS variables at the top of the file (`:root`).

### Interactions
Edit behavior in:
- `assets/js/main.js`

Includes:
- Scroll progress + sticky nav behavior
- Mobile drawer logic
- Reveal animations and counters
- Parallax effects
- Back-to-top button

## Deployment

This site can be deployed easily to:
- GitHub Pages
- Netlify
- Vercel
- Any static hosting platform

Deploy by uploading the repository contents and serving `index.html` as the entry page.

## Accessibility Notes

The project includes accessibility-friendly patterns such as:
- Skip-to-content link
- Keyboard-friendly navigation flow
- Visible focus styles
- Reduced-motion handling for users with motion preferences
